# MoRead · 墨知 1.4.1

## 中文

- 伴读会话支持导出 Markdown，可分享或另存；阅读页伴读悬浮球可在设置中隐藏。
- 改进主动段评的前方段落选择、全章覆盖和断点补全，避免后半章长时间没有段评。
- 改进 EPUB 重复资源兼容；章节精排解析失败时保留正文与图片，并保护已有正文和批注坐标。
- TXT 单本预览与批量导入改用流式处理，降低大文件内存占用；优化章节扫描与导入进度。
- 书架支持调整网格列数；优化书籍详情加载、段落讨论及悬浮导航的拖拽、切页和收放。
- 修复底部弹层滚动边界与视口稳定性，补充导航手势、导入和段评回归覆盖。

正式安装包：`mozhi-1.4.1-vc85.apk`，Android 8.0 及以上，使用正式发布证书，可覆盖安装已有正式版。

## English

- Export companion conversations as Markdown for sharing or saving, and optionally hide the companion bubble in the reader.
- Improve proactive annotation scheduling, chapter coverage, and resumable completion.
- Handle duplicate EPUB resources and preserve text and images when rich chapter parsing fails, while protecting existing text and annotation coordinates.
- Stream TXT previews and batch imports to reduce memory use; improve chapter scanning and import progress.
- Add configurable bookshelf grid columns and refine book-detail loading, passage discussions, and floating navigation gestures.
- Stabilize bottom-sheet scrolling and viewport boundaries, with additional navigation, import, and annotation regression coverage.

Official package: `mozhi-1.4.1-vc85.apk`, for Android 8.0 or later. Signed with the official release certificate for upgrades from existing official installations.
